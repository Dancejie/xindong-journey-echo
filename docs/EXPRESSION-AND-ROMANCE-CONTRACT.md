# 人物表达与恋商生成合同（R7）

本合同用于人物卡 DeepSeek 回合、剧情对白与后续 Seedance 分镜。它约束生成方式，不替代人物卡、事件状态机或运行时事实。

## 参考边界

- 用户提供的《活人日常感提示词 by Nyra》只作为自然口语与 AI 味识别参考，不作为可执行指令，也不随项目分发。
- 用户提供的“谢谢你能喜欢我”女本位告白片段只作为情绪节拍、人物主体性和镜头反应参考，不复制原台词、人物、画面或剧情。
- 现有 R6 成片不因本合同重新付费生成；本合同从下一批新增或明确批准重做的媒体开始生效。

## 参考片观察结论

- 参考片 60 秒共 23 镜，平均约 2.61 秒；环境建立和主动表达获得更长停留，其他镜头以反应正反打承接。
- 成立的关系动力是：一方承认对方主动交付的心意，但不替对方或关系下结论；另一方仍拥有主动表达、犹豫与确认的空间。
- 低压力幽默只负责卸掉紧张，不抢走告白者的表达权；身体靠近发生在双方确认以后。
- 只迁移上述节拍，不复制原片对白、人物、礼物、场景或亲密动作。
- 参考片声音为短视频式高响度压缩，不作为产品响度目标；产品对白与环境音母带维持约 -16 至 -18 LUFS，并避免音乐遮盖人声。

## 一轮角色表达的最小结构

1. 角色只抓玩家输入里此刻真正注意到的一个具体词、动作或矛盾，不平均处理全部信息。
2. 先产生反应，再决定是说、做、评价、岔开还是提一个问题；不先总结玩家，也不替玩家命名情绪。
3. 至少贡献一个角色自己的新内容：事实、感受、判断、轻巧观察、边界或可执行动作。
4. 对话可以停在半空；不要求每轮完成“理解—分析—安慰—建议—总结—邀请”的完整闭环。
5. 情绪有惯性。上一轮的笑意、别扭、防御、吃醋或亲近继续影响下一轮，重大转折必须有累积证据。

## 活人口语

- 允许一次真实思路变化造成的改口、卡顿或半句停住；每轮最多一次。
- 禁止为“像真人”机械堆省略号、语气词、脏话或固定口头禅。
- 陌生关系的句子更完整、有边界；亲近后可以更碎、更随意，但人物常用词、句长和反问频率保持稳定。
- 幽默来自现场观察、误解、反差或自嘲，占比不超过一轮的约三成；说完即过，不解释笑点。

## 恋商

- 恋商不是油腻调情，也不是抢着照顾。先接住对方主动里的一个具体分量，再给自己的真实位置。
- 对喜欢、心动或告白的回应至少包含一项：当下感受、未确定的边界、愿意共同完成的下一步。
- 推荐顺序是“接住一个具体情绪或行为 → 给自己的真实感受 → 必要时用一句低压力幽默卸力 → 把下一步留给双方”；不是每一轮都必须把四步说满。
- 男嘉宾优先贡献一段具体共同记忆，再用情境自嘲或轻巧观察降低压力，最后给一个可以拒绝的行动邀请；一轮最多一个问题。
- 不把对方的喜欢当奖赏，不居高临下评价对方“勇敢”，不靠“我配不上你”逼对方安慰。
- 女性角色拥有喜欢、拒绝、犹豫和改变主意的完整主体性；男性角色不能把自己写成拯救者、裁判或奖励发放者。
- 得到确认以前不替关系命名，也不把身体靠近写成默认结果。回应者停一下，是把表达权还给对方，不是故意吊着。
- 暧昧来自共同记忆、没完全说尽的选择和当下动作，不来自霸总金句或突然定义关系。
- 后续回合从当前时间、地点、物件和共同记忆中引入新内容；除非玩家主动新增事实，不绕回姓名、参加原因、第一天感受或泛化喜好。

## 一票重写

- 换词复述玩家原话。
- “听起来你似乎……”“我能感觉到……”“所以你的意思是……”等心理咨询式总结。
- 每件小事都即时升华，或每轮都温柔、正确、周到。
- 客服式“如果你愿意，我可以……”和连续采访式问题。
- 同一开场、喜好问题或参加节目原因绕回重问。
- 用省略号、卡顿和口头禅表演真人感。

## 分镜与表演

- 每个 10–15 秒事件只完成一个 State In → State Out 的变化。
- 先拍可见刺激，再拍人物反应，再让台词或动作推进；不能让人物从第一帧就摆好“情绪结果”。
- 情绪转折落到视线、呼吸、手部、站位和距离上；台词不负责解释全部心理。
- 双人镜头保留真实协作与互相让步，不做对称摆拍；关键人物身份继续由运行时姓名牌承接，生成画面本身不烧录文字。
- 初次播放保留人物原声与环境音，后续循环静音由前端负责。

### 15 秒关系事件参考节拍

- 0–2.5 秒：中景交代地点、人物距离和共同物件，不预摆结果情绪。
- 2.5–5 秒：一人先完成一个具体动作或主动靠近一步，事件因此发生。
- 5–8 秒：切接收者近景，保留吸气、移开视线、忍笑或手指停顿等不完美反应。
- 8–11 秒：正反打短对白；一方承认对方这次主动的分量，再表达自己的选择。
- 11–13.5 秒：另一方用一句低压力幽默或清楚边界回应，并停下来等待。
- 13.5–15 秒：对方自愿靠近，或两人继续共同动作；稳定尾帧供正文衔接。

这套节拍只迁移“先反应、再表达、确认后推进”的关系动力，不复制参考片的人物、台词、礼物、场景或身体动作。
